# 복약도우미

Flutter 기반 복약 관리 앱의 첫 MVP입니다. 현재 데이터와 알림은 사용 중인 기기에 저장됩니다.

## 현재 구현

- 약 이름, 1회 복용량, 복용 시각 등록
- 성분, 효능, 복용 안내 메모 입력
- 등록 정보 기기 내 저장
- 매일 반복되는 복약 알림 예약
- 약 정보 수정과 복약 알림 켜기·끄기
- 일반 알림과 소리·진동 알람 선택
- 약별 복용 중·복용하지 않음 상태와 복용 중단일 기록
- 약사 화면에서 현재 복용약과 과거 복용약 구분 표시
- 복용하지 않는 약의 알림 자동 중지
- 약 정보 상세 보기 및 약 삭제
- GitHub Actions에서 Android APK 자동 빌드

## 다음 구현 단계

- 약 봉지·처방전 촬영과 OCR
- 알약 모양·색·각인 기반 식별 후보 검색
- 식약처 의약품 정보 API 연동 및 출처 표시
- 촬영 결과를 확인한 후 약으로 등록하는 검토 화면

촬영 인식은 약을 확정하는 기능이 아니라 등록을 돕는 기능으로 설계합니다. 약 이름과 복용법은 약 봉투 또는 처방전과 대조해 확인해야 합니다.

## 실행

Flutter SDK를 설치한 뒤 프로젝트 폴더에서 아래 명령을 실행합니다.

    flutter create --platforms=android --org com.hyuckiii --project-name my_pharmacy .
    python3 tool/prepare_android.py
    flutter pub get
    flutter run

Android 알림은 사용자가 허용해야 표시됩니다. 소리 알람은 Android의 “알람 및 리마인더” 권한이 허용되면 정확한 시각으로 예약하며, 권한이 없으면 일반 시각 알림으로 대체됩니다. 알림은 기기 음량·방해 금지 설정의 영향을 받으며, 기본 시계 앱처럼 계속 울리는 알람은 아닙니다. 약 등록 데이터는 현재 앱 내부에만 저장되며, 기기 변경이나 앱 삭제에 대비한 백업은 아직 제공하지 않습니다.

## APK

main 브랜치에 push하거나 Actions 탭에서 Android APK 빌드를 실행하면 APK가 workflow artifact로 업로드됩니다.

## 안전 안내

이 앱은 복용 기록과 알림을 관리하는 용도입니다. 처방이나 약사의 안내를 대신하지 않습니다. 앱에 적은 효능·복용 안내는 사용자가 확인한 정보를 기록하는 메모이며, 복용량이나 복용법을 앱이 판단하지 않습니다.
